# GigaChat Streaming Assistant

## Описание

Этот проект представляет собой интеллектуального ассистента на базе нейросети GigaChat.
Система разработана с использованием FastAPI и предоставляет возможность общаться с ИИ в режиме реального времени через протокол WebSocket. Ответы от нейросети приходят мгновенно по мере их генерации (стриминг), что обеспечивает высокую скорость взаимодействия.

## Установка
Python 3.10+ должен быть уже установлен. Затем используйте pip для установки зависимостей:

```
pip install -r requirements.txt
```

Далее необходимо создать файл с расширением .env в корневой папке проекта и внести в него параметры:

1. GIGACHAT_CREDENTIALS="ваш авторизационный ключ GigaChat"
2. GIGACHAT_SCOPE="GIGACHAT_API_PERS" (или другой доступный вам scope)
3. GIGACHAT_MODEL="GigaChat" (название модели по умолчанию)

Для получения GIGACHAT_CREDENTIALS необходимо зарегистрироваться на портале [GigaChat API](https://developers.sber.ru/docs/ru/gigachat/quickstart/ind-create-project) и создать новый проект.

## Запуск
Убедитесь, что файл index.html находится в той же директории, что и основной файл программы.

Запустите сервер разработки с помощью uvicorn:


```uvicorn main:app --reload```, 

либо:

```fastapi dev main.py```

После запуска проект будет доступен по адресу: [localhost](http://127.0.0.1:8000)
